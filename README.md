# EVoC WASM

A from-scratch port of [TutteInstitute/evoc](https://github.com/TutteInstitute/evoc)
(Embedding Vector Oriented Clustering) to **Rust** and **Zig**, compiled to
WebAssembly for clustering embeddings in the browser.

Work in progress. Both ports match the Python reference against shared fixtures.
